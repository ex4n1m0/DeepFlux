Capabilities

Torrent engine

A full BitTorrent engine with stream-while-downloading — start watching from the first megabytes while the rest arrives. Rate limits, sequential mode and rechecks are one chat message away.

Install & trust

Know exactly what you’re running

Windows 10 / 11 · 64-bit
v5.2 · 370.6 MB · per-user install, no admin · updates itself in-app
Download setup
  1. Download the setup file above and run it — it installs per-user, no UAC prompt, and keeps your settings on upgrades.
  2. Optionally let the installer set up Jackett torrent search for you (one checkbox, one click).
  3. If Windows shows “protected your PC”: More info → Run anyway. The build is unsigned — an independent developer certificate is the one thing still on the shopping list. The checksum below is your integrity check.

A shared AI key is built in, so the agent works out of the box. It is replaced with every release — keep DeepFlux updated, or set your own key under File → API Keys to be fully independent.

macOS 14+ · Apple Silicon (M1–M4)
v4.7 · 336.6 MB · beta — Intel Macs not supported yet
Download .dmg
  1. Download the .dmg, open it and drag DeepFlux to Applications.
  2. First launch: right-click DeepFlux.app → Open → Open. The build is unsigned, so Gatekeeper needs that explicit first OK (once only).
  3. Add your AI key under File → API Keys — DeepSeek, OpenRouter or any OpenAI-compatible endpoint.

No built-in AI key on macOS — bring your own. The beta carries everything except the media-player tab: agent, browser, torrents & downloads, room and file manager.
