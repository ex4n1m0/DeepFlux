下载安装程序
  1. 下载上方安装包并运行 —— 按用户安装、没有 UAC 弹窗，升级时会保留你的设置。
  2. 可以让安装程序顺便帮你配好 Jackett 种子搜索 （一个勾选，一次点击）。
  3. 如果 Windows 提示“已保护你的电脑”：点“更多信息” → “仍要运行”。构建未签名 —— 独立开发者证书还在计划中。 下方校验和可用于完整性验证。

内置共享 AI 密钥，智能体开箱即用。密钥随每次发布 更换 —— 请保持 DeepFlux 更新，或在“文件 → API 密钥”里 填入自己的密钥以完全独立。

  1. 下载 .dmg，打开后把 DeepFlux 拖进 “应用程序”。
